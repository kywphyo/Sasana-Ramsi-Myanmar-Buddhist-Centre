# Tharthana Ranthi Wihara - Monastery Website Template

This is a fully functional website template for a monastery, featuring a responsive design, smooth scrolling navigation, and interactive elements.

## Features

- Responsive design that works on desktop and mobile devices
- Fixed navigation header with smooth scrolling
- Hero section with call-to-action
- About section with image
- Services section showcasing monastery activities
- Gallery section with placeholder images
- Contact form with basic validation
- Mobile-friendly hamburger menu
- Fade-in animations on scroll

## File Structure

```
/
├── index.html          # Main HTML file
├── css/
│   └── style.css       # Main stylesheet
├── js/
│   └── script.js       # JavaScript for interactivity
└── images/
    ├── monastery.svg   # Monastery building illustration
    ├── meditation.svg  # Meditation hall illustration
    ├── garden.svg      # Garden illustration
    ├── statue.svg      # Buddha statue illustration
    └── group.svg       # Group meditation illustration
```

## Customization

1. **Content**: Edit the text in `index.html` to match your monastery's information.

2. **Styling**: Modify `css/style.css` to change colors, fonts, and layout.

3. **Images**: Replace the SVG files in the `images/` folder with your own images. Keep the same filenames.

4. **Contact Form**: The contact form currently shows an alert. To make it functional, integrate with a backend service like Formspree, Netlify Forms, or your own server.

5. **Additional Pages**: Add more HTML files (e.g., about.html, events.html) and update the navigation accordingly.

## How to Use

1. Open `index.html` in a web browser to view the website.
2. For development, use a local server to avoid CORS issues with file:// protocol.

## Technologies Used

- HTML5
- CSS3 (with Flexbox and Grid)

- SVG for illustrations

## Browser Support
